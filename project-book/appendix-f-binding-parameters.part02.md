### 4. מצבי מודל השפה למשחק המילולי / LLM Modes for the Verbal Game

טבלה זו מתעדת את ארבעת מצבי ההפעלה של מודל השפה, שכולם נוגעים **אך ורק** לטקסט ההטעיה — **הכרעת המהלך היא תמיד אלגוריתמית ובקוד פייתון** (ראו פרק 6). המצב נבחר בקובץ התצורה הפרטי (`[trash_talk] provider`), והוא הקובע כמה מתוך **[אומדן טוקנים לסדרה]** תוציא הקבוצה על דיבור. *טבלה זו היא טבלת ייחוס בלבד — הבחירה פרטית לכל עמית, אינה חלק מקובץ התצורה המוסכם ואינה נתונה למשא ומתן.*

| מצב | היכן רץ ועלות טוקנים | מגבלת קצב | חשבון והתקנה |
|---|---|---|---|
| **[ספק תבנית]** (`template`) | בתהליך; משפטים מוכנים מראש בקוד — **אפס טוקנים**. ברירת המחדל | — | ללא; לא מקוון וחינמי |
| **[ספק אולמה]** (`ollama`) | מודל *מקומי* ב־`localhost:11434` — אפס טוקני API | ללא | התקנת Ollama ומשיכת מודל |
| **[ספק ענן]** (`claude_api`) | מודל ענן קטן (Haiku) דרך ה־API — צריכה אמיתית הנספרת מול **[אומדן טוקנים לסדרה]** | לפי החשבון | מפתח API של Anthropic (חשבון בתשלום) |
| **[ספק שורת הפקודה]** (`claude_cli`) | `claude -p` דרך ה־CLI של Claude Code — העלות הגבוהה ביותר | לפי המנוי | התחברות ל־Claude CLI (מנוי) |

הפרמטר `every_n_steps` מפעיל את המודל רק אחת לכמה תורות ומצמצם עוד את הצריכה. במצבי `template` ו־`ollama` ניתן לשחק את כל הסדרה בת **[מספר המשחקונים]** המשחקונים ב־**אפס טוקנים**, וכל התחרות עוברת לאיכות אלגוריתם התנועה.

### 5. בחירת מודול האסטרטגיה / Strategy Module Selection

מדיניות התנועה — **ליבת הציון** — נבחרת בקובץ התצורה הפרטי (`[strategy]`). בהשארת המקטע ריק רץ המוח ההיוריסטי המשולב במימוש הייחוס; כדי להריץ אסטרטגיה משלכם, הַצביעו מאחד המפתחות אל מחלקה היורשת מ־`BrainBase` ודורסת את `_pick_move` (ואצל השוטר גם את בחירת המחסום ב־`_decide_move`). *טבלה זו היא טבלת ייחוס בלבד — הבחירה פרטית לכל עמית ואינה נתונה למשא ומתן.* פירוט מלא ב־`docs/STRATEGY.md` ובנספח ד.

| מפתח (`[strategy]`) | תפקיד | כיצד לדרוס |
|---|---|---|
| `thief_class` | מוח הגנב שלכם, בכתיב `package.module:Class` | ירשו מ־`ThiefBrain` ודרסו את `_pick_move` ו/או `_decide_move` |
| `police_class` | מוח השוטר שלכם | כנ״ל; ב־`_decide_move` של השוטר נבחר גם המחסום |
